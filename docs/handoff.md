# SIDEPICK 작업 인수인계

기준일은 2026년 10월 8일 KST다. 실행 방법과 로컬 데이터 정책은 [기기별 개발 환경](work-environment.md)에 있다.

## 현재 상태

회사 작업 폴더는 `C:\Users\USER\Documents\New project\SidePick`다. 문서 정리 시작 시 `main`의 `cceed24` 커밋이 GitHub와 일치했으며 미커밋 변경은 없었다.

현재 코드는 네이버 쇼핑 검색과 DataLab 쇼핑 클릭 추이를 이용해 후보를 조사하고 SQLite 스냅샷 및 HTML과 JSON 보고서를 만든다. 매출, 판매량, 정확한 검색량을 추정하는 기능으로 취급하지 않는다. Windows와 macOS 설치 안내가 README에 있다.

## 기기 간 작업에서 남은 문제

API 설정은 각 기기의 `.env`에 있다. 수집 이력 DB와 보고서는 GitHub에 올라가지 않는다. 두 기기에서 기존 이력을 이어 사용할지 각각 독립된 이력으로 개발할지 결정해야 한다. 이번 정리에서는 실제 API 접속과 수집 결과를 검증하지 않았다.

## 다음 작업

1. 맥에 저장소를 clone하고 Python 3.10 이상과 가상환경을 준비한다.
2. API 설정과 카테고리 ID를 각 기기에 설정한다.
3. `python -m sidepick.cli --help`로 CLI 구성을 확인한다.
4. 기존 관측 이력이 필요하면 회사 SQLite DB를 별도로 백업하고 이전한다.
5. 실제 수집 후 실행 시각, 사용 카테고리, 결과와 남은 문제를 이 문서에 기록한다. 비밀 값은 제외한다.

## 이번 정리의 검증 범위

GitHub 브랜치와 로컬 상태, 의존성, CLI, 설정 로딩 코드를 확인했다. 의존성 설치, API 수집과 DB 변경은 수행하지 않았다. 맥 실행 검증은 남아 있다.
